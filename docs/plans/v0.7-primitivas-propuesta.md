# Plan de Implementación: Arquitectura de Primitivas Componibles (Fontex 0.7.0 → 0.8.0)

## 1. Visión y Cambio de Paradigma

El objetivo de la versión **0.7.0 / 0.8.0** es transformar Fontex de un editor basado en módulos didácticos cerrados (19 guías fijas) a un **lienzo visual matemático-científico componible** (experiencia tipo Canva con motor tipo GeoGebra), orientado tanto a docentes de Matemática y Física como al público general.

### Principios de Arquitectura
1. **Composición sobre Especialización:** En lugar de crear componentes aislados por cada tema (ej. *Módulo de Área*, *Módulo de Fracciones*, *Módulo de Vectores*), se implementan **9 primitivas base** combinables entre sí.
2. **Reactividad por Variables Compartidas (`sceneVars`):** Cualquier primitiva puede leer variables numéricas globales de la escena (ej. `a`, `theta`, `r`), permitiendo vincular controles deslizadores con gráficas, figuras geométricas y fórmulas LaTeX en tiempo real.
3. **Seguridad y Determinismo:** La IA (`studio-agent`) **no genera código ejecutable**; únicamente compone árboles JSON validados con Zod/JSON Schema que el motor local de Fontex interpreta y renderiza.
4. **Compatibilidad con `visual_scenes`:** El nuevo esquema mantiene el límite máximo de **1 MiB por escena**, hasta **80–120 objetos** por lienzo y soporte para exportación limpia a PDF.

## 2. Contrato Base de Escena y Primitivas (`src/types/canvas-primitives.ts`)

Todos los objetos del lienzo heredan de `BasePrimitive` para garantizar un único motor de selección, arrastre, redimensionado, rotación, historial (`Undo/Redo`), agrupación por pasos de presentación y exportación.

```typescript
export type PrimitiveKind =
  | 'coordinate_canvas' // 1. Plano cartesiano / polar / cuadrícula
  | 'function_region'   // 2. Curvas f(x), paramétricas y áreas sombreadas
  | 'vector_segment'    // 3. Vectores, rectas tangentes, cotas y segmentos
  | 'stamp_grid'        // 4. Pictogramas, conteo, bloques base 10 y arreglos
  | 'math_block'        // 5. Texto enriquecido + LaTeX reactivo a variables
  | 'control_slider'    // 6. Deslizadores e interruptores de variables globales
  | 'geometric_shape'   // 7. Polígonos, círculos con sectores, sólidos y cuerpos físicos
  | 'data_chart'        // 8. Tablas de valores, barras, pastel, dispersión y regresión
  | 'annotation_stroke';// 9. Trazo libre a mano alzada y globos de llamada (callouts)

export interface SceneVariable {
  name: string;         // ej. "a", "theta", "x_0"
  value: number;
  min: number;
  max: number;
  step: number;
  unit?: string;        // ej. "rad", "deg", "m/s"
}

export interface PrimitiveStyle {
  strokeColor: string;
  fillColor: string;
  strokeWidth: number;
  opacity: number;
  dashed?: boolean;
  fontSize?: number;
}

export interface BasePrimitive {
  id: string;
  kind: PrimitiveKind;
  label?: string;
  // Geometría en el lienzo (en píxeles lógicos)
  x: number;
  y: number;
  width: number;
  height: number;
  rotation: number;     // grados
  zIndex: number;
  locked?: boolean;
  // Control de presentación docente (aparece en el paso N)
  presentationStep?: number;
  style: PrimitiveStyle;
}
```

## 3. Especificación Técnica de las 9 Primitivas

### 3.1. `coordinate_canvas` (Escenario Matemático)
Contenedor con sistema de coordenadas propio. Puede funcionar como objeto independiente o como padre (`parentId`) donde se anclan curvas, puntos y vectores.
* **Propiedades clave:**
  * `mode`: `'cartesian' | 'polar' | 'unit_circle' | 'number_line' | 'blank_grid'`
  * `domainX`: `[number, number]` (soporta expresiones o variables)
  * `rangeY`: `[number, number]`
  * `angleUnit`: `'rad' | 'deg'`
  * `showGrid`: `boolean`, `showAxisLabels`: `boolean`, `subdivisions`: `number`

### 3.2. `function_region` (Curvas y Áreas Sombreadas)
Resuelve el renderizado de funciones, derivadas, tangentes e **integrales definidas / áreas entre curvas** (superando la limitación de solo texto de la v0.6.0).
* **Propiedades clave:**
  * `canvasId`: `string` (referencia al `coordinate_canvas` donde se proyecta)
  * `expression`: `string` (ej. `"a * x^2 + b * x + c"`, `"sin(x)"`)
  * `secondaryExpression?: string` (opcional: para sombreado entre $f(x)$ y $g(x)$)
  * `pointsOfInterest`: `Array<{ xExpr: string; label?: string; showCoords?: boolean }>`
  * `showDerivative?: boolean`
  * `shadedRegions`:
    ```typescript
    Array<{
      fromExpr: string;   // ej. "0" o variable "a"
      toExpr: string;     // ej. "3" o variable "b"
      fillColor: string;
      showCalculatedArea: boolean; // Calcula integral numérica por Simpson/Trapecio
      label?: string;
    }>
    ```

### 3.3. `vector_segment` (Vectores, Cotas y Rectas Dirigidas)
* **Propiedades clave:**
  * `canvasId?: string` (si existe, `start` y `end` usan coordenadas matemáticas; si no, píxeles del lienzo)
  * `start`: `[string, string]` (ej. `["0", "0"]` o `["x_0", "f(x_0)"]`)
  * `end`: `[string, string]`
  * `headEnd`: `'arrow' | 'dot' | 'bar' | 'none'`
  * `headStart`: `'arrow' | 'dot' | 'bar' | 'none'`
  * `showMagnitude?: boolean`
  * `showAngleArc?: boolean`

### 3.4. `stamp_grid` (Pictogramas y Matemática Concreta)
Pensado para Aritmética, Inicial, Primaria y conteo combinatorio.
* **Propiedades clave:**
  * `icon`: `'apple' | 'star' | 'cube' | 'coin' | 'circle' | 'atom' | 'custom_svg'`
  * `rowsExpr`: `string` (ej. `"3"` o variable `"filas"`)
  * `colsExpr`: `string` (ej. `"4"` o variable `"cols"`)
  * `activeCountExpr?: string` (resalta $k$ elementos de $N$ para representar fracciones o conjuntos)
  * `groupBy?: number` (agrupa visualmente en decenas/centenas)

### 3.5. `math_block` (Texto y LaTeX Reactivo)
Bloque de texto estilo Canva con soporte para interpolación de variables del lienzo mediante sintaxis `{{expr}}`.
* **Propiedades clave:**
  * `markdownContent`: `string` (ej. `"El área sombreada entre $x={{a}}$ y $x={{b}}$ es **{{round(area, 2)}} $u^2$**."`)
  * `variant`: `'card' | 'transparent' | 'callout_info' | 'callout_step'`
  * `autoHeight`: `boolean` (crece y se reduce automáticamente sin recortar texto)

### 3.6. `control_slider` (Interactividad en Vivo)
Permite manipular las `SceneVariable` directamente en el lienzo o en modo presentación.
* **Propiedades clave:**
  * `variableName`: `string`
  * `controlType`: `'slider' | 'stepper' | 'play_pause'` (el modo `play_pause` anima automáticamente la variable para simular movimiento o barridos de ángulo)
  * `speed?: number`

### 3.7. `geometric_shape` (Geometría Euclidiana y Cuerpos Físicos)
* **Propiedades clave:**
  * `shape`: `'triangle' | 'polygon' | 'circle_fraction' | 'sector' | 'prism' | 'cylinder' | 'inclined_plane' | 'block_mass'`
  * `verticesExpr?: Array<[string, string]>` (para polígonos dinámicos)
  * `divisions?: number`, `shadedSlices?: number` (para tortas/barras de fracciones)
  * `showAngles?: boolean`, `showSideLengths?: boolean`, `showCenterOfMass?: boolean`

### 3.8. `data_chart` (Tablas y Estadística)
* **Propiedades clave:**
  * `chartType`: `'table_only' | 'bar' | 'histogram' | 'pie' | 'scatter'`
  * `headers`: `[string, string]`
  * `rows`: `Array<{ label: string; valueExpr: string }>` (puede vincularse a una función para autogenerar la tabla de tabulación $(x, f(x))$)
  * `showLinearRegression?: boolean`

### 3.9. `annotation_stroke` (Pizarra Libre y Señaladores)
* **Propiedades clave:**
  * `mode`: `'freehand' | 'highlighter' | 'callout_bubble'`
  * `points`: `Array<[number, number]>` (simplificado con algoritmo Ramer-Douglas-Peucker para mantener el JSON ligero)
  * `calloutText?: string`

## 4. Extensión del Motor Matemático (`src/lib/math-engine/`)

Para soportar estas primitivas sin dependencias pesadas en el cliente:

1. **Evaluador de Contexto (`evaluateInScene`):**
   * Extender el parser actual para recibir un diccionario `scope: Record<string, number>` con todas las `SceneVariable` activas.
   * Añadir funciones auxiliares para textos dinámicos: `round(n, d)`, `abs(n)`, `deg(rad)`, `rad(deg)`.
2. **Integrador Numérico (`computeDefiniteIntegral`):**
   * Implementar regla compuesta de **Simpson 1/3** (con $n = 200$ subintervalos) sobre el dominio `[from, to]`.
   * Detectar discontinuidades o asíntotas (cuando $|f(x)| > 10^6$ o `NaN`) para dividir el polígono SVG de relleno en sub-regiones seguras y evitar artefactos visuales.
3. **Generador de Polígonos de Sombreado (`buildShadedAreaPath`):**
   * Muestrear $f(x)$ desde $x = a$ hasta $x = b$.
   * Si existe $g(x)$, muestrear $g(x)$ en sentido inverso desde $x = b$ hasta $x = a$ y cerrar el path SVG (`Z`). Si no existe $g(x)$, cerrar contra el eje $y = 0$ (acotado a la ventana visible del plano).

## 5. UX Estilo Canva en el Lienzo (`/#/lienzo`)

Para lograr la facilidad de "arrastrar, ordenar y presentar":

* **Paleta Lateral Unificada (Izquierda):**
  * **Pestaña 1: Plantillas Rápidas** (reemplaza las 19 guías rígidas por plantillas editables organizadas por nivel/rama: *Aritmética, Álgebra, Geometría, Trigonometría, Cálculo, Física*).
  * **Pestaña 2: Elementos (Las 9 Primitivas)** con inserción de 1 clic o arrastrar al lienzo.
  * **Pestaña 3: Variables y Sliders** para crear parámetros compartidos.
* **Barra Contextual Flotante (Superior sobre selección):**
  * Al seleccionar cualquier objeto, muestra únicamente las 4–5 acciones directas de esa primitiva (ej. al seleccionar una función: `[Color de curva]`, `[Sombrear área]`, `[Mostrar derivada]`, `[Tabla de valores]`, `[Duplicar]`).
* **Modo Presentación por Pasos:**
  * Botón **"Presentar"** que oculta las herramientas de edición y permite avanzar con flechas del teclado mostrando progresivamente los objetos según su `presentationStep`.
* **Exportación a PDF sin cortes:**
  * Aplicar `break-inside: avoid; page-break-inside: avoid;` a cada contenedor de primitiva y calcular el salto de página por bloques completos.

1. Actualizar el **JSON Schema (Structured Outputs)** de la Edge Function `studio-agent` para que devuelva operaciones atomizadas sobre las 9 primitivas:
   * `upsert_variable`
   * `add_primitive`
   * `update_primitive`
   * `delete_primitive`
   * `load_template`
2. Incluir en el *System Prompt* reglas de composición visual (distribución en rejilla sin solapamiento: gráfico a la izquierda `x: 40, width: 520`, explicación y tabla a la derecha `x: 590, width: 380`).
3. Validar toda respuesta de la IA en el cliente con `validateScenePatch()` antes de aplicarla al estado del lienzo y guardarla en `visual_scenes`.
