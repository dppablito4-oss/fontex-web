# General canvas

The general canvas is the primary editor at `/#/lienzo`, with `/#/laboratorio` retained as an alias. `/#/lienzo-clasico` redirects to the general canvas. The previous implementation remains in Git history and its backup branch; its test materials are retired.

A scene contains shared expression records and generic elements (`formula`, `plot`, `table`, `text`). Elements refer to expressions by ID. There is no topic-specific module registry in this renderer. The same expression tree drives numerical evaluation, symbolic differentiation, polynomial extraction, root finding and graph sampling. Parameters a/b/c are shared across the scene and persisted with it.

Supported grammar: numbers, x/a/b/c, pi/e, arithmetic, powers, implicit multiplication, parentheses, sin/cos/tan/ln/exp/sqrt; one equality becomes a residual expression. Trigonometry uses radians. Expressions are parsed into a bounded AST; JavaScript and HTML are never evaluated. Root solving isolates real polynomial roots recursively using derivative critical points and bisection, up to degree four, including repeated roots. The graph is a sampled approximation, omits undefined values and clips the plot window.

The authenticated `scene-agent` proposes only validated scene JSON. Direct expression entry, parameter changes and calculations are local and do not call AI. Local storage is isolated by account; JSON import/export and print/PDF are available. Scene titles support 160 characters; accepted scenes and their formatted JSON exports fit within 1 MiB, also below the cloud storage limit. Authenticated scenes synchronize directly to `visual_scenes` in Supabase using owner RLS and revision compare-and-set. Conflict reconciliation advances its base only after confirming that no local edits interrupted the merge, preserving both device versions.

There is no automatic import from the old Studio workspace or prototype. The retirement migration deletes the old test workspaces and imported module scenes, revokes client access to `studio_workspaces`, and prevents old clients from inserting legacy scenes again. Opening the new canvas removes the retired browser caches while retaining native scenes and account sessions. Generic formula/plot/table/text scenes are the only supported format. Guest scenes remain local. Complex roots, integrals, general multivariable functions and 3D are outside this first version.

Validation: expression engine tests compare symbolic derivatives against finite differences, verify degree-2/3/4 roots and residuals across coefficient scales, and cover parameter exponents at zero. Regression tests exercise an edit during asynchronous conflict reconciliation, malformed remote rows, retired cache removal and a file-input round trip above the former 300 KB limit. SQL tests cover owner RLS, revision checks, retirement and rejection of legacy data. Edge tests verify authentication and reject executable expressions. Earlier browser QA covered desktop/mobile, reactive parameters, composition and PDF rendering; this correction is verified with automated tests.
